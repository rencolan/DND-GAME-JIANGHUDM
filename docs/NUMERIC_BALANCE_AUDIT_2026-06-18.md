# 数值审查与武学扩展建议

日期：2026-06-18

范围：
- 当前物品数值
- 当前武学数值
- 当前 Boss 数值
- 后续新增金庸武学的扩展方向

---

## 一、结论先说

当前版本的主要问题不是“某个 Boss 高了 5 点 HP”，而是数值结构过于扁平：

- 武学目前几乎只由 `damageDice`、`baseQiCost`、`linkedAbility` 决定。
- Boss 目前主要靠更高的 `HP / AC / 伤害骰` 形成压迫。
- 物品目前几乎只有回复数值，没有战斗节奏和流派构筑价值。

这会导致一个直接结果：

- 原著里最有魅力的武学差异，例如身法、拆招、吸功、点穴、反制、蓄力、压制，在当前结构里会退化成“伤害骰面值不同”。

所以建议分两步走：

1. 先把现有数值压回一个可玩的区间。
2. 再扩充武学池，但不要只扩充名称，必须同步扩充武学效果维度。

## 三、关键失衡点

## 1. 玩家与 Boss 的伤害档位跨得太大

当前玩家前期主力输出大多在：

- `1d4` 平均 `2.5`
- `1d6` 平均 `3.5`
- `1d8` 平均 `4.5`

当前 Boss 主力输出大多在：

- `2d6` 平均 `7`
- `2d8` 平均 `9`
- `3d8` 平均 `13.5`

这不是“略强”，而是直接跨了一个世代。

如果按当前命中逻辑粗算，Boss 的回合平均压力大致如下：

- 黑衣刺客：约 `1.8 ~ 2.2` 每回合
- 丁春秋：约 `4.1 ~ 4.8` 每回合
- 游坦之：约 `3.5 ~ 4.2` 每回合
- 鸠摩智：约 `5.4 ~ 6.4` 每回合

而玩家用常见开局武学打 Boss 的期望输出大致只有：

- `少林内功` 打丁春秋：约 `1.22`
- `一阳指` 打丁春秋：约 `1.80`
- `一阳指` 打鸠摩智：约 `1.57`

这意味着：

- 丁春秋和鸠摩智在当前模型下，更像数值墙，而不是机制型宗师。

## 2. Boss 的 Qi 只是展示，不是真正约束

当前敌方每回合会随机从武学池里选招，并结算 `enemyQiCost`，但不会在出招前检查是否还有足够 Qi。

结果就是：

- Boss 可以在理论上内力耗尽后，继续无限打 `火焰刀`、`化功大法`、`冰蚕毒掌`。

这会让 `Qi` 成为伪资源。

## 3. 物品价值单一，而且战斗中可免费使用

当前物品设计只有：

- 直接回血
- 直接回气

而且在当前实现中，使用物品不会消耗战斗行动，也不会自动推进敌方回合。

结果就是：

- 物品更像“暂停菜单回血”，而不是战术资源。
- 只要库存够，玩家可以在高压战里无代价续航。

这会破坏 Boss 的节奏压迫感。

## 4. 武学状态大多没有真正的机械落点

当前 `enemyStatusAdd` 确实会把状态挂上去，例如：

- `exposed`
- `露出破绽`

但这些状态主要只是显示出来，并没有形成稳定的命中、伤害、反制或防御变化。

结果就是：

- 控制、拆招、破绽、失衡，都还停留在文案层。

## 5. 装备当前没有数值身份

现在有：

- `weapon`
- `armor`
- `accessory`

但它们没有提供稳定的数值影响。

这意味着：

- 装备不会改变构筑。
- Boss 掉落装备缺乏吸引力。
- 物品线和武学线是割裂的。

## 6. 六脉神剑当前面值过高

`6d8` 的平均伤害是 `27`。

如果暴击翻倍骰数，则会来到平均 `54` 的级别。

这在当前系统里不是“后期绝学”，而是“几乎直接跳过战斗”。

所以六脉神剑绝不能直接按当前模型落地为常规可用招式。

## 四、物品数值建议

## 1. 先给物品做功能分层

建议把物品拆成 4 类：

- 回复类：回血、回气、解内伤
- 战术类：烟雾、迷药、暗器、石灰包
- 防护类：解毒丹、护心丸、金创绷带
- 装备类：武器、防具、饰品

## 2. 回复类建议

前期建议总回复预算不要过高。

建议改成：

- `金疮药`：`恢复 6 HP`
- `行气散`：`恢复 2 Qi`
- 新增 `止血散`：`恢复 4 HP，并清 1 层流血`
- 新增 `解毒丸`：`不回血，解除中毒/寒毒`

建议规则：

- 战斗中使用消耗 1 次行动。
- 战斗中使用后，正常进入敌方回合。

这样物品才是“为节奏付费”的资源，而不是免费翻盘按钮。

## 3. 装备类建议

装备不要加太大数值，避免把武侠做成传统 RPG 换装堆数值。

建议用“小而明确”的差异：

- 武器：
  - 轻兵器：命中 `+1`
  - 重兵器：伤害 `+1`
  - 奇门兵器：特定武学 `+2` 命中或附带效果
- 防具：
  - 轻甲：`AC +1`
  - 软甲：受到内功伤害 `-1`
  - 厚甲：受到外功伤害 `-1`
- 饰品：
  - 玉佩：`Max Qi +1`
  - 佛珠：首次受到内伤时减 1
  - 扳指：指法类武学伤害 `+1`

## 4. Boss 掉落物建议

建议每个 Boss 至少掉 1 个“有风格的装备/秘药”，而不是只掉剧情名目：

- 丁春秋：`星宿毒囊`、`避毒香囊`
- 游坦之：`冰蚕寒丝护腕`
- 鸠摩智：`火焰刀残谱`、`密宗火纹佛珠`

## 五、武学数值建议

## 1. 先把武学分成 5 个数值层级

建议以后新增武学都按这 5 档设计：

- 入门：`1d4 ~ 1d6`
- 熟练：`1d6 ~ 1d8`
- 进阶：`1d8 ~ 2d4`
- 上乘：`2d6 ~ 1d10`
- 绝学：`2d8 ~ 3d6`

不建议常规可重复使用技能直接上：

- `3d8`
- `4d8`
- `6d8`

因为当前系统没有冷却、蓄力、虚招、反噬、硬直成本来接住这种面值。

## 2. 武学不要只用伤害区分

建议新增最少 6 个效果维度：

- `role`：爆发 / 控制 / 反制 / 身法 / 资源 / 续航
- `tags`：掌法 / 指法 / 剑气 / 毒功 / 轻功 / 擒拿
- `statusOnHit`：中毒 / 失衡 / 破绽 / 封脉 / 寒毒
- `selfBuff`：加闪避 / 加护体 / 回气 / 蓄势
- `cooldown`：强绝学避免每回合重复用
- `qiRule`：耗气 / 回气 / 吸气 / 透支

如果不加这些维度，加入再多金庸武学，最后也只会变成：

- 这个叫降龙十八掌，2d8
- 那个叫黯然销魂掌，2d8
- 另一个叫玄冥神掌，2d8

这样会浪费 IP 价值。

## 3. 现有武学调整建议

建议先这样压数值：

- `一阳指`：保留 `1d8`
  - 定位：稳定单点内功
- `少林内功`：从纯伤害技改成 `1d4`，但命中后给自己 `+1 护体` 或回 `1 Qi`
- `大理心法`：不要作为输出招，改成“回气/稳态”型内功
- `巷尾轻功`：不要只是 `1d4`，应附带“本回合被反击命中率降低”

Boss 武学建议：

- `化功大法`：从 `2d8` 下调到 `2d6`
  - 命中后追加“玩家下回合内功耗气 +1”或“Qi -1”
- `三笑逍遥散`：保持 `2d6` 或降到 `1d8`
  - 主要卖点应是中毒、失衡、封位
- `摘星手`：`1d10` 可留
  - 但命中后更适合附带“下回合外功命中 -1”
- `冰蚕毒掌`：从 `2d8` 降到 `2d6`
  - 附加寒毒
- `火焰刀`：从常驻 `3d8` 改为 `3d6+2` 或 `2d8+2`
  - 并加冷却/蓄力/阶段触发
- `小无相功`：不要做直伤技
  - 改成强化下一招、复制标签、降低耗气
- `龙爪擒拿`：`2d6` 或 `2d8` 均可
  - 重点是擒拿、打断、压制近身

## 4. 六脉神剑建议

不建议直接做成常规 `6d8`。

建议改为以下两种方案之一：

- 方案 A：`3d6`，但无视 `1~2` 点护体/防御，且命中后附加“贯穿”
- 方案 B：蓄力技
  - 平时 `2d6`
  - 消耗额外 `2 Qi` 后升级为 `4d6`

这样既保留神兵级压迫感，又不会直接摧毁战斗长度。

## 六、Boss 数值建议

## 1. 建议的 Boss 档位

按照当前系统节奏，建议用 4 档：

- 精英怪：`HP 24~30 / AC 12~13 / Qi 3~5`
- 小 Boss：`HP 32~38 / AC 13~14 / Qi 6~8`
- 正式 Boss：`HP 40~48 / AC 14~15 / Qi 9~12`
- 终局宗师：`HP 48~56 / AC 15~16 / Qi 12~16`

## 2. 对当前 Boss 的具体建议

### 黑衣刺客

当前：

- `24 / 12 / 3`

评价：

- 数值合理，可以保留。
- 适合作为前期试刀对象。

建议：

- 不改面板。
- 给它一个“先手刺杀”特性即可。

### 丁春秋

当前：

- `46 / 15 / 12`

评价：

- 面板不算离谱，但配 `2d8 + 2d6 + 1d10` 的伤害池后，已经偏成硬压。

建议：

- 保持 `HP 44~46`
- `AC` 降到 `14`
- 把强度转到毒、削气、乱节奏

推荐改法：

- `化功大法`：`2d6`
- `三笑逍遥散`：`1d8` + 中毒/失衡
- `摘星手`：`1d10`

### 游坦之

当前：

- `40 / 13 / 8`

评价：

- 面板没问题，但武学池太直给。
- 他更适合做“缠斗莽夫 + 寒毒压迫”，不适合当第二个纯输出 Boss。

建议：

- 保持 `HP 38~40`
- `AC 13`
- 让寒毒成为核心

推荐改法：

- `冰蚕毒掌`：`2d6`
- `铁头硬撞`：`1d10`
- `生死符反劲`：`1d6`，但附带反制或减速

### 鸠摩智

当前：

- `52 / 16 / 16`

评价：

- 面板符合终局宗师，但 `火焰刀 3d8` 让他在当前模型下太像爆杀怪。

建议：

- 保持 `HP 50~52`
- `AC 15~16`
- 把威胁改成“阶段 + 读招 + 绝学时刻”

推荐改法：

- 第一阶段：
  - `龙爪擒拿 2d6`
  - `小无相功 0~1d6`，但为下一招加成
- 第二阶段：
  - `火焰刀 2d8+2` 或 `3d6+2`
- 第三阶段：
  - 低血量触发一次强化 `火焰刀`

这样更像宗师，而不是每回合都在抡核弹。

## 1. 如果你坚持世界观纯《天龙八部》

- 拈花指

这些武学的好处是：

- 世界观一致

- 风格覆盖足够广

建议定位：

- 北冥神功：资源成长

## 八、建议的首批新增武学数值

以下数值是按“当前项目应先可玩，再逐步扩机制”的原则给的，不追求一步到位。

### 天龙体系优先表

- 北冥神功
  - 类型：内功 / 成长
  - 建议：`1d4`
  - 耗气：`1`
  - 特效：命中后 `回复 1 Qi`，但同一战斗每 2 回合最多触发 1 次

- 凌波微步
  - 类型：身法 / 防守
  - 建议：`1d4`
  - 耗气：`1`
  - 特效：本回合若未击杀目标，则敌方下次攻击命中 `-2`

- 降龙十八掌
  - 类型：外功 / 爆发
  - 建议：`2d6`
  - 耗气：`0` 或 `1`
  - 特效：若本次命中超过 DC `5`，追加“震退”

- 打狗棒法
  - 类型：兵器 / 控制
  - 建议：`1d8`
  - 耗气：`0`
  - 特效：命中后给敌方 `破绽`

- 天山六阳掌
  - 类型：掌法 / 稳态
  - 建议：`1d10`
  - 耗气：`1`
  - 特效：命中后自身 `AC +1`，持续 1 回合

- 天山折梅手
  - 类型：近战 / 反制
  - 建议：`1d8`
  - 耗气：`1`
  - 特效：如果敌方本回合使用外功，则额外 `+2` 命中

- 生死符
  - 类型：特殊 / 控制
  - 建议：`1d6`
  - 耗气：`2`
  - 特效：命中后附加“封脉”或“失衡”

- 斗转星移
  - 类型：反制
  - 建议：`1d4`
  - 耗气：`2`
  - 特效：本回合若被命中，反弹 `1d6`

- 参合指
  - 类型：指法 / 点杀
  - 建议：`1d10`
  - 耗气：`1`
  - 特效：对已有 `破绽` 的目标伤害 `+2`

- 拈花指
  - 类型：指法 / 精准
  - 建议：`1d8`
  - 耗气：`1`
  - 特效：命中 `+1`

## 九、代码层建议

如果下一步要正式做内容扩展，建议不要继续只靠 `damageDice` 撑武学差异。

最低限度建议补这些字段：

```ts
interface MartialArt {
  role?: "burst" | "control" | "counter" | "mobility" | "resource" | "stance";
  tags?: string[];
  cooldown?: number;
  minQi?: number;
  statusOnHit?: string[];
  selfBuff?: string[];
  armorBreak?: number;
  qiGainOnHit?: number;
  qiDrainOnHit?: number;
}

interface Item {
  combatActionCost?: 0 | 1;
  attackBonus?: number;
  acBonus?: number;
  qiBonus?: number;
  grantsStatus?: string[];
  curesStatus?: string[];
}
```

只要把这层补上，后面的金庸武学扩展才会真的“长得不一样”。

---

## 十、建议的执行顺序

最稳的落地顺序：

1. 修战斗漏洞
   - 敌方出招前检查 Qi
   - 战斗中使用物品要消耗行动
   - 让状态有真实效果
2. 压 Boss 面值
   - 先把 `3d8`、`6d8` 这类极端值收回来
3. 做武学效果分层
   - 身法、反制、吸功、控制先能表达
4. 再扩充武学池
   - 先扩《天龙八部》
   - 再扩广义金庸群侠

---

## 最终建议

如果只给一句策划判断：

- 当前版本可以继续保留“丁春秋 + 游坦之 + 鸠摩智”这套人物框架。
- 但不能继续靠提高 `HP / AC / 伤害骰` 来表达宗师感。
- 在扩充更多金庸武学之前，必须先给武学和物品补上“控制、反制、身法、资源、状态”这几个机制出口。

否则你加得越多，最后越像只是往列表里继续塞更大的伤害骰。
